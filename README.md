# Harshit Dubey — 3D Portfolio

A futuristic, interactive portfolio built with React, TypeScript, Vite, Three.js and Framer Motion.

## ✨ Highlights

- Interactive 3D scene with pointer-reactive depth
- Cinematic hero section and smooth section transitions
- Responsive project showcase with expandable-style presentation
- Skills constellation / spatial visualization
- Journey, achievements and contact sections
- Resume download support
- Clean data-driven project structure for adding future projects

## 🧠 Design Philosophy

The portfolio treats 3D as an interaction and depth system rather than a decorative object. Content layers, floating elements, perspective, hover movement and spatial composition are used to make the interface feel like a digital workspace.

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Drei
- Framer Motion
- Lucide React

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## 📦 Build

```bash
npm run build
```

## ➕ Adding Projects

Projects are represented through a data array in the React application. Add another project object there instead of rebuilding the project UI.
